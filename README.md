# Johnson Bolhayon - Portfolio

Personal portfolio site. Next.js 15 (App Router) + TypeScript + Tailwind 4, React Three Fiber for the 3D scene, GSAP ScrollTrigger for motion. Deployed on Vercel.

Work in progress - see `docs/PLAN.md` for the build plan.

## Scripts

```bash
npm run dev          # dev server (Turbopack)
npm run check        # typecheck + lint + confidentiality guard
npm run build:local  # production build with a 2 GB heap (small machines)
```
